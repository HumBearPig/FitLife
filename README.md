# FitLife — консольный фитнес-бот

*От автора: Данное описание написал полностью ИИ, т.к. текст мне писать некогда.*

Учебный проект: консольный бот FitLife, который помогает людям следить за здоровьем.
Компания FitLife разрабатывает приложение для контроля здоровья; мобильной версии пока нет,
но инвесторам нужен работающий прототип.

## Что умеет бот

- знакомится с пользователем,
- узнаёт его параметры (вес, рост),
- рассчитывает индекс массы тела (ИМТ),
- даёт рекомендацию по потреблению воды.

Пользователь должен почувствовать заботу — значит, интерфейс (пусть и текстовый) вежливый,
а результаты — понятные и полезные.

## Как считаются показатели

- **ИМТ:** `bmi = user_weight / (user_height ** 2)`, результат округляется до одного знака после запятой.
- **Норма воды:** 30 мл на каждый килограмм веса, затем перевод в литры (`water_needed / 1000`).
  30 мл на килограмм — стандартная рекомендация для поддержания водного баланса.

## Как запустить

Нужен Python 3, внешние библиотеки не требуются. В терминале из папки проекта:

```bash
python fit_life.py
```

Бот попросит имя, возраст, вес (в кг) и рост (в метрах).

## Пример работы

Ввод: Анна, 25 лет, 75.5 кг, 1.8 м.

